# Larasell Starter Kit

A Laravel starter kit that scaffolds a complete e-commerce storefront powered by [Larasell](https://larasell.dev).

## Create a new store

```bash
laravel new --using larasell-dev/starter-kit my-store
```

## What's included

- Product listing and product detail pages
- Cart with quantity updates, promotions, and shipping options
- Checkout with order confirmation
- Order history for customers
- Login and registration
- Order confirmation e-mails
- Example shipping methods and promotion
- Catalog seeder (`php artisan app:seed-catalog`)

## Getting started

```bash
composer run setup
```

Then start the dev server:

```bash
composer run dev
```
